# Atividade 1
Repositório referente aos arquivos da Atividade 1 da disciplina.

## Execução
Tenha este repositório clonado localmente. Após isso, basta abrir a pasta no VSCode e rodar o ```index.html``` com a extensão "Live Server" (ou similar).

## Organização
- A raiz da pasta contém o arquivo html central e este readme.
- ```\info```: contém as especificações e uma imagem do funcionamento do projeto.
- ```\public```: contém a imagem usada pelo projeto.
- ```\script```: contém o código js que regula o projeto.
- ```\style```: contém o arquivo css.
